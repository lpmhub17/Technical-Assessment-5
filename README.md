# CS054 Exercise 2 – Sentiment Analysis

FEU Institute of Technology · College of Computer Studies · CS054 (Intelligent Systems)

## Files

| File | Description |
|------|-------------|
| `sentiment_activity.py` | Laboratory Activity: classifies 10 sentences with TextBlob polarity and prints a Positive / Neutral / Negative summary |
| `challenge_happy_sad.py` | Challenge: counts happy and sad words using `number_happy()` and `number_sad()` and reports the tone |
| `happy_words.txt`, `sad_words.txt` | Word lists used by the challenge (swap in a larger public lexicon, e.g. Hu & Liu opinion lexicon) |
| `CS054_Exercise2_Sentiment_Analysis.pdf` | Write-up with code, screenshots and output |

## Running

```bash
pip install textblob
python sentiment_activity.py
python challenge_happy_sad.py
```

The challenge program only needs the Python standard library.
